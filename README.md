# game-engine

The `game-engine` service for a two-player, hidden-information strategy board game (Stratego/Kriegsspiel-inspired). Part of a multi-repo system — see `docs/architecture.md` for the full picture and how this service fits in.

Built as a learning project for a Python/FastAPI, cloud-native microservices stack.

## Stack

Python, FastAPI, asyncio, Poetry, Postgres (via SQLAlchemy async + Alembic), pytest.
