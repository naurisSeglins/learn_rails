# Dev Journal

Session-by-session personal log — what I did today/this session, what clicked, what I got wrong, what's blocking me. This is distinct from `TASKS.md` (which tracks *tasks* — status per ticket) and `task_learning_notes/` (which tracks *concepts* — the deep How-it-works breakdown per ticket). This file tracks *me* — a session can span multiple tickets, and captures the reflective stuff (misconceptions, wins, blockers) that doesn't belong in either of those.

Newest entry at the top. One entry per session/day, even if brief.

## Template

```
## YYYY-MM-DD — <session focus, e.g. "Phase 0 Ticket 2 continued">

- **Worked on:** terse pointer, not a restatement — link to the TASKS.md ticket and/or the
  task_learning_notes file that has the actual detail.
- **Win:** something that specifically clicked or worked, stated concretely — not "went well."
- **Misconception named:** the *general* category of the mistake, not just the specific fix —
  should transfer to the next unrelated case, not just this one.
- **Blocker:** what's actually stopping me right now (a task-state fact — may be "none").
- **Open question:** a genuine knowledge gap for next session or to raise with Claude — distinct
  from the blocker above (a blocker stops the task; a question is something I don't understand yet).
- **Retrieval check:** can I explain [the concept from today] back in my own words right now?
  Yes/no + one line. Same checkpoint TASKS.md already asks for per-ticket, just run daily here too.
```
