# Exercises

See `../exercises.md` for the log, conventions, and how assignment/review works.

Each exercise gets its own numbered folder here:

```
exercises/
  01_some_topic/
    PROMPT.md          <- the assignment: goal, constraints, what "done" looks like
    exercise.py        <- your solution
    test_exercise.py   <- a self-check, where one's feasible for the topic
```

Nothing in this directory is part of the `game-engine` service — it's practice scratch space, not shipped code.
